# 🦀 Treinamento Rust

Repositório criado para registrar meus estudos e exercícios em Rust.

## Objetivo

Aprender os fundamentos da linguagem Rust através de exercícios práticos, explorando conceitos importantes como:

* Variáveis e mutabilidade
* Shadowing
* Condicionais (`if` e `else`)
* Loops (`loop`, `while` e `for`)
* Entrada de dados pelo terminal
* Match expressions
* Funções
* Structs
* Ownership e Borrowing (em andamento)

## Estrutura do Projeto

```text
TREINAMENTO_RUST
├── shadowing
├── loop_while_for
│   ├── exercicio01
│   ├── exercicio02
│   ├── exfor
│   └── exwhile
```

Cada pasta contém exemplos e exercícios desenvolvidos durante o processo de aprendizagem.

## Tecnologias

* Rust
* Cargo
* Git
* GitHub

## Como executar

Clone o repositório:

```bash
git clone https://github.com/CrisanCesar/treinamento_rust.git
```

Acesse um dos exercícios:

```bash
cd nome_da_pasta
cargo run
```
